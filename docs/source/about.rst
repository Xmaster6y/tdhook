About
=====

TDHook is an open-source library for interpretability with ``torch`` hooks and
``TensorDict``.

* `Source code <https://github.com/Xmaster6y/tdhook>`_
* `PyPI package <https://pypi.org/project/tdhook/>`_
* `MIT License <https://github.com/Xmaster6y/tdhook/blob/main/LICENSE>`_
